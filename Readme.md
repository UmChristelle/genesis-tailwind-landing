 # Genesis Tailwind SaaS Landing Page

This project is a modern SaaS landing page built using HTML and Tailwind CSS, inspired by the Genesis template.

## Features
ero section with call-to-action and stats

Features / use cases grid with hover effects

Why Choose Us section highlighting benefits

Call-to-Action (CTA) section with background pattern

Fully responsive design

Footer with multiple columns and social links

Tailwind CSS utility-first styling

Semantic HTML5 elements (header, main, section, footer)

Font Awesome icons

## Technologies Used
- HTML5
- Tailwind CSS (CDN)
